# L'Oréal Paris · Claims Intelligence Engine

React + Vite front end.

## Run
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in /dist
```

## Structure
- `src/data/` – claims, sample studies, study types (replace with API calls)
- `src/components/` – Header, ClaimsSidebar, ClaimSummary, SamplePicker, StudyForm
- `src/styles/` – tokens (brand colours/fonts), base, layout, components
- `src/App.jsx` – state and page composition

## Brand tokens
Edit `src/styles/tokens.css` to change colours and fonts.
